YouTube-API-Schlüssel (optional)

Nur nötig, um YouTube-Links automatisch zu finden und Playlists zu importieren. Kostenlos: Google Cloud Console → Projekt anlegen → „YouTube Data API v3“ aktivieren → Anmeldedaten → API-Schlüssel. Reicht für ca. 100 Suchen pro Tag. Der Schlüssel bleibt nur in diesem Browser.
